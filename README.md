## Aim:
To design a basic mobile and web layout for the HealthMate healthcare application by applying Gestalt principles, incorporating UI elements and design patterns, developing interaction behaviours, and creating a suitable brand logo following UI/UX design guidelines.

## Algorithm:
1. Identify the requirements of the HealthMate healthcare application.
2. Create a brand logo using Canva with suitable colours and typography.
3. Design the mobile splash screen and home screen using Figma.
4. Create doctor profile and video consultation screens.
5. Design a responsive web dashboard for managing patients and appointments.
6. Apply Gestalt principles such as Proximity, Similarity, Continuity, Closure, Figure-Ground and Alignment.
7. Incorporate UI elements such as buttons, cards, icons, search bars and navigation menus.
8. Develop interaction behaviours such as smooth transitions, instant feedback and easy navigation.
9. Apply usability principles such as consistency, readability, accessibility and visual hierarchy.
10. Review and finalize the mobile and web layouts.
